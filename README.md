Коммерческий проект/дипломная работа для оптимизации производства завода ЕвроХим по заказу ПроТех Лаб. 
Программа рассчитывает количество воды для того чтобы оптимально извлечь KCL из сильвинитовой руды.

После получения данных оператор знает как физически скорректировать подачу воды, тем самым увеличить качество готовой продукции (KCL) и увеличить прибыль компании.

Стек: Java21, JavaFX, Scene Builder, Maven
